# Gerador de Conselhos (Advice Generator App)

Um aplicativo web simples que gera conselhos aleatórios para o usuário. Este projeto foi desenvolvido para praticar a estruturação de layouts com HTML5 e a estilização com CSS3

Desenvolvido para o curso **DevQuest** 



# Rode o site no seu navegador
https://guspelepe.github.io/Gerador-De-Conselhos/

**Status do Projeto:** Em desenvolvimento (Trabalhando na integração com JavaScript).

## O Projeto

O objetivo deste projeto é construir a interface de um gerador de conselhos, garantindo que o layout seja fiel ao design proposto e que os elementos estejam centralizados e responsivos na tela. 

No momento, a estrutura visual da aplicação está concluída. O botão de gerar novos conselhos está posicionado, mas a funcionalidade de buscar um novo conselho será implementada nas próximas atualizações.

## Tecnologias Utilizadas

- **HTML5** 
- **CSS3**
