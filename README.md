O **Gerador de Conselhos** é uma aplicação web simples e direta desenvolvida para fornecer frases inspiradoras e motivacionais. O projeto oferece uma experiência visual limpa e responsiva, com interações agradáveis e um sistema prático de sorteio de conselhos locais.

<img width="1912" height="938" alt="image" src="COLOQUE_O_LINK_DA_IMAGEM_PRINCIPAL_AQUI" />


## Funcionalidades Principais

*   **Sorteio Aleatório:** Gere um novo conselho instantaneamente ao clicar no botão de dado. O sistema seleciona aleatoriamente entre 100 frases motivacionais pré-programadas.

<br>

*   **Design Totalmente Responsivo:** 
    *   Adapta-se perfeitamente a dispositivos móveis e desktops.
    *   O layout muda de forma fluida para telas menores (abaixo de 600px), ajustando o tamanho da fonte e substituindo o divisor visual automaticamente.
 
<br>

*   **Efeitos Visuais e Interações:**
    *   **Glow Effect:** O botão principal possui uma transição suave que emite um brilho verde neon ao passar o mouse.
    *   **Animação de Clique:** O botão sofre uma leve redução de escala ao ser clicado, fornecendo um feedback visual tátil para o usuário.

##  Tecnologias Utilizadas

*   **Front-end:** HTML5, CSS3, JavaScript (Vanilla ES6).
*   **Estilização:** CSS puro focado em Flexbox para o alinhamento centralizado e uso de variáveis de cor em formato `hsl`.
*   **Dados:** Array local no JavaScript atuando como um "banco de dados" contendo 100 objetos com IDs e textos exclusivos.
*   **Reset de CSS:** Utilização de um `reset.css` para padronizar margens, preenchimentos e box-sizing em todos os navegadores.


## Inicio do Projeto

Este projeto foi desenvolvido como uma excelente forma de praticar os fundamentos do desenvolvimento web, focando em manipulação de DOM com JavaScript, responsividade e efeitos de estado de hover no CSS. É um projeto mais simples e enxuto, ideal para consolidar a lógica de programação básica e a estilização de componentes do tipo "card".
